## 实际修复与保留证据

CI 使用 `V2 Signer:` 输出时，原核验器错误地识别不到证书；修复兼容确认过的格式，保留唯一证书、预期摘要与 Debug 拒绝，并测试源戳/不完整摘要边界。三层打包曾出现 Java heap space，CI 改为 4 GiB 堆和 2 worker。

首次部署的 OSS 端点缺少 HTTPS/Bucket 配置，保护流程恢复了热更关闭版本；之后的真实分片 PUT 因固定 MIME 未纳入 V4 默认签名失败。配置和 MIME 签名修正后，对同一正确 Bucket 候选重跑成功。后端身份变化的旧会话拒绝记录保留。

正式包的真实入口发现 `FileNotFoundException: shaders/white-sphere.agsl`：幕布错误使用薄宿主 Activity Context。修复为当前业务 Context；窗口与生命周期仍由 Activity 管理。原宿主设备测试直接启动演练场，没有覆盖首页幕布，已改经真实入口。测试前置曾误点设置页同名标题和后台窗口，修复先回首页并限定目标包名；这些失败均保留，不当作成功。

旧预发 APK、旧基线 `fde9a677…` 仅作为复现记录，不是正式发布/恢复目标。最终候选使用上述新基线。文件与日志在忽略的 `.local/hot-production-*`、CLI 的 `.local/production-baseline-fixed-1.0.10-20261002` 等目录。
