## 单版本边界

热更目标明确为 `targetVersionCode=17`，与宿主接口契约独立。真实 API 测试：17 收到预期候选；18 和未上报版本的 0 收到 `none`，强行请求激活或对象下载授权返回 422。Android 单元测试同时验证本地拒绝错版本；热更加载及稳定冷启动再次检查系统安装版本。回退必须属于同一版本。

服务端保留历史清单省略字段时的原始不可变表示，避免新增字段破坏旧登记恢复包。新 CLI 的 `init` 必须指定目标版本；`pack` 拒绝遗漏，增量保留签名清单。详见[单版本规则](../native-hot-single-version.md)。
