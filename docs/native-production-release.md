# 原生 APP 发版准备

生产 API 与 OSS 已接入。公开安装配置由仓库变量 `NATIVE_HOT_CONFIG_JSON` 提供，固定 `app.luoxianlv / production / HTTPS`，自动检查开启，测试健康回报关闭。APK 的根公钥必须与服务端相同；配置只含公钥及公共参数，不含管理令牌、内容私钥或 OSS 凭据。

## 发包入口

- `原生签名包准备`：手动生成正式证书签名的候选 APK，检查实际三层 SDK、资源、映射与内置组合，只保存 Actions artifact。APK 和较大的 SDK/映射资料分别归档，方便先下载安装包。
- `Release`：正式发布入口。手动默认使用原生包；标签触发时，`NATIVE_RELEASE_DEFAULT=true` 且标签源码含 `app-host` 才选择原生路线。旧标签源码继续走旧路线；手动重建旧标签时明确关闭 `native_package`。
- 当前准备版本为 1.0.10 / 17。这里只修改源码及配置，不创建 `v1.0.10` 标签，不发布 GitHub Release，不更新 OSS 的 APP 下载清单。公众下载仍是 1.0.9。

原生构建使用 JDK 21、4 GiB Gradle 堆和最多 2 个 worker；常规 CI 另保留旧发包路径检查。正式签名核验保持 apksigner 成功、唯一证书、预期 SHA-256 和非 Debug 证书要求，兼容实际 CI 的 `V2 Signer:` 格式；源戳或不完整摘要不能作为安装证书。
