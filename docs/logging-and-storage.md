# 中文日志与可查看文件目录

## 目录

通过 `Context.getExternalFilesDir(null)` 取得当前 Android 用户的应用专属目录，不硬编码用户编号或主存储路径。主用户通常为：

- 正式版：`/storage/emulated/0/Android/data/app.luoxianlv/files/`
- 内部测试版：`/storage/emulated/0/Android/data/app.luoxianlv.debug/files/`

| 子目录 | 内容 |
| --- | --- |
| `wallpapers/<UUID>/` | 导入的原始项目；`.root` 记录项目根的相对路径 |
| `logs/play-debug.log`、`.1` | 当前和上一份日志，UTF-8 无 BOM |
| `logs/shots/` | 最近 15 张识别截图 |
| `diagnostics/` | 可分享的诊断 ZIP |
| `updates/` | 更新 APK 与下载临时文件，下载器保留最近两个安装包 |
| `imports/` | 导入期间的临时 ZIP，结束时删除 |

支持 Shizuku 的文件管理器可在获得相应权限后访问该目录；应用自身无需 Shizuku 或全盘存储权限。工作资料和多用户下以实际系统返回路径为准。外部存储不可用时回退内部目录，日志首条会记录实际位置。账号凭据与偏好设置不迁出。

## 迁移

应用启动后在后台迁移旧 `files/wallpapers` 和更新包，不阻塞首屏。先复制到同盘临时目录并校验长度及源文件是否变化，再重命名发布；失败保留源数据，目标已有内容不覆盖。当前选择使用同一 UUID，迁移前兼容读取旧路径，迁移后优先外部路径。

为避免已预加载场景仍引用内部路径，旧壁纸保留至下次启动，确认外部项目存在后再清理。日志线程在首次追加前迁移旧 `files/playback-debug` 和 `cache/updates` 中的诊断 ZIP；同名新日志保留，旧日志另存为 `.legacy-时间戳` 文件。

## 日志约定

自有日志统一使用 `AppLog`，同时写入 Logcat 和文件，格式为 `时间 [中文级别][模块] 消息`。中文事件保留坐标、显示尺寸、耗时、错误码、状态和异常堆栈；第三方引擎及系统异常保留原文，并附中文上下文、来源文件和行号，不改协议字段或历史日志。

后台单线程队列上限 256，队列繁忙或写入失败不会阻塞演奏，后续成功记录会给出丢弃任务数。日志按 8 MiB 轮转；目录扫描限频至 30 秒，截图及导出后另行检查，总诊断留存上限 50 MiB。导出前等待写入屏障，快照期间持锁；ZIP 保留原始 JSON 字段并增加中文说明。

`FileProvider` 仅授权更新包和诊断包子目录，不开放壁纸根目录或整个外部存储。

## 注释与编码

自有 Android 源码、测试和壁纸桥接代码使用简洁中文说明，保留线程、坐标、时序、兼容性及失败恢复约束。标识符、API、协议字段和第三方源码保持原样；删除过时注释和已注释的废弃实现。修改文件使用 UTF-8 无 BOM。

## 验证

新增迁移测试覆盖中文文件、完整复制、目标冲突、失败保留源文件；Android 测试覆盖真实外部路径、壁纸选择与延迟清理、旧日志迁移、UTF-8 无 BOM、完整异常和 FileProvider 读取 ZIP。演练场与系统 ZIP 导入沿用现有回归。

验证结果：合并远端入口改版及测试调整后，84 项单元测试中 82 项通过、2 项可选样本跳过；外部存储与日志、演练场完整流程、系统 ZIP 导入及图片/视频/网页渲染回归通过。源码 UTF-8 无 BOM 和无替换字符检查通过。
