# 渲染引擎通用优化（2026-09-28）

## 边界

不修改任何壁纸原始项目，不按工坊 ID 特调，不降低渲染分辨率、帧率上限、粒子数量、着色效果或动画时长。现有解析器和离线沙箱权限保持不变。

## 实现

- `lifecycle.mjs` 合并原生暂停和文档隐藏状态，只在状态变化时调用引擎，解决重复暂停清空恢复列表、页面可见事件误恢复的问题。
- `PracticeBackdrop` 明确暂停 JS 引擎后再暂停 WebView；异步回调检查视图身份和最新状态，避免快速返回时旧回调再次暂停。继续复用预加载场景，不调用影响其他 WebView 的全局 pauseTimers。
- 场景恢复仅交给场景控制器恢复原来播放的图层，不再启动所有隐藏视频图层。直接视频壁纸继续使用原来的控制路径。
- 实际壁纸就绪后释放预览 Drawable；渲染器失败时按需重新读取预览。选择器按卡片像素尺寸解码；内存压力时释放压缩预览缓存和未使用的首页场景缓存，不销毁正在使用的演练场。
- 视频和动态图纹理上传复用当前 GL 上下文的最大纹理尺寸，消除每次上传的重复驱动查询。
- 开场碎片复用顶点投影，每片每帧从 36 次透视投影减少到 8 次；缓存不变的三角函数。退出粒子复用同帧共享波形。保留随机种子、几何、材质和时序。

## 包体

普通 `assembleDebug` 保留开发调试能力；可用 `-PcompactDebug=true` 生成经过 R8 和资源裁剪的内部测试分发包，不打包 Compose 调试工具。两者共用 `.debug` 包名和 debug Analytics 空实现。

`BuildConfig.INTERNAL_BUILD` 表示内部版本行为，与是否允许连接调试器分开：精简包仍跳过隐私/统计流程，正式版仍执行原流程。发布精简包时应同时保存 `outputs/mapping/debug/mapping.txt`。

不对原始壁纸视频转码；内置大型壁纸仍会直接增加包体，不能把删壁纸算作引擎优化。

## 验证

- Node：时间桥接、挂载前暂停、重复暂停、页面隐藏与原生暂停交错、恢复和清理；直接测试已打包引擎的场景及视频恢复控制器。
- Android：实际首页预加载实例复用、进入/退出转屏、双击入口、退后台返回、JS 场景真实暂停状态。
- 原始 scene ZIP：四个时段切换、视频帧变化、重复暂停释放视频源、恢复只启动一个可见视频图层。
- Android 单元测试：85 项，83 通过，2 项可选测试跳过，0 失败。
- 精简包用纯 Android Framework 黑盒测试，避免测试程序依赖已经被 R8 删除的内部 Kotlin 类；正常开发包仍可使用完整 PracticeInstrumentation。

## 体积实测

十进制 MB；同一组对比是否内置壁纸保持一致。

| 包 | 优化前 | 精简后 |
| --- | ---: | ---: |
| 不内置壁纸的 Debug | 35.80 MB | 12.05 MB |
| 内置原始伊蕾娜壁纸 | 116.74 MB | 93.86 MB |

内置 scene.pkg 长度仍为 84,230,588 字节，并与原始版本逐字节比较一致。轻量包减小约 66.3%；内置原始壁纸版约 19.6%。

没有在同一台实体手机上进行前后帧耗时和功耗对比，因此不承诺整体帧率提升百分比。顶点计算次数属于算法计数，不是 FPS 测量。
