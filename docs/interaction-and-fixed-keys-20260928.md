# 交互与固定琴键兼容（2026-09-28）

## 变更

- 口琴 AudioTrack 直接混音，不再按键申请或释放音频焦点，避免壁纸暂停或被压低音量。后台、退出及输出异常仍按原生命周期停止口琴。
- 悬浮球只在手动拖到左右边缘后半隐藏，200 ms 内降到 45% 不透明度。拖回屏内恢复，取消手势回位；展开面板保持完整可见，显示尺寸变化后保留停靠方向。
- 发现页标题、搜索入口与曲目放进同一惰性列表，小窗可以从页头起手滚动；曲名最多两行，作者最多一行，调整窗口大小保留列表位置。保持系统原有滚动惯性。
- 设置新增「实验性选项 → 口琴按键位置固定」，默认关闭。开启后复用演练场的几何计算，首音和转屏恢复均不申请截图；固定布局不写回自动识别缓存，切换选项会暂停当前播放。
- 演练场内直接读取真实音区；其他软件无法读取音区，初次播放前需自然音、半音关闭，播放中勿手动切换。外部口琴布局需与演练场一致，固定坐标不意味着任意游戏布局都兼容。
- 删除壁纸「项目文件夹」选择入口。壁纸仍统一安装到 `/storage/emulated/0/Android/data/<包名>/files/wallpapers`。
- ZIP 与 MIDI 共用 `ImportFilePicker`：系统 chooser 包装 `ACTION_GET_CONTENT`，兼容普通文件管理器返回的单个 URI 或 ClipData；取消选择不导入。是否显示 MT 等应用取决于手机安装的版本是否声明该文件选择接口。

## 验证

- JVM：91 项，89 通过，2 项依赖私人截图的可选测试跳过，失败 0。
- `InteractionInstrumentation`：真实自由窗口页头拖动、列表滚动、缩窗保留位置通过；左右半隐藏位置以实际窗口坐标验证，透明度、拖回、取消及展开边界通过。
- `WallpaperSoundInstrumentation`：背景媒体焦点不会被口琴连续八次按键/释放改变；默认静音、开启壁纸音并演奏、后台恢复各完整循环通过。
- `ExperimentalInstrumentation`：受 FLAG_SECURE 保护、截图无法识别且不读取演练场状态的窗口中，八键/升降调/半音演奏通过；关闭开关后恢复识别失败路径，原识别缓存保留；ZIP/MIDI 的选择协议、URI、ClipData 和取消处理通过。
- 固定布局坐标单测覆盖手机横竖屏、华为示例尺寸和平板比例。

## 测试边界

模拟器禁用宿主音频输出，验证的是焦点事件与播放器状态，未做听感评价。模拟器解码高分辨率视频时手势回调延迟可造成快节拍跳过；坐标回归将壁纸挂起并降低测试节拍，音视频循环单独测试。尚不能据此量化真机帧率提升，也未安装 MT 管理器进行端到端选取。

复用同一几何与文件选择协议，避免两套位置/导入逻辑漂移；停靠边界单独测试，不改变播放调度算法。发版、远端推送、OSS 清理均保持暂停。
