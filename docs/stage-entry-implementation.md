# 演练场入口与转屏（2026-09-28 修订）

## 当前行为

首页插画下方的入口只保留居中的「演练场」，没有圆环、箭头或壁纸缩略图。整张卡可点击。

进入时，首页卡片在 520ms 内展开为纯渐变幕；演练场先继承当前方向，绘制同样的不透明幕。Android 10 及以上等待首帧提交，再请求横屏；旧系统隔两个动画帧请求横屏。窗口有焦点、配置已横屏、显示旋转和尺寸连续 400ms 不变，才创建琴键、揭幕并展开琴键。旋转过程中不绘制按钮装饰，也不提前显示实际琴键。

选中壁纸的预览与音源可以提前准备；WebView、视频解码和着色器初始化延后到琴键开场动画结束。首个动态画面准备好后，从预览切换到动态壁纸。默认背景使用已有轻量静态图，不创建 WebView。

退出立即停止音符和无障碍播放，合幕后回到首页，再收回入口。保留双击去重、后台结束演奏、首页方向恢复和深色主题。

## 包体

删除 Debug assets 中的 default-wallpaper（伊蕾娜 scene.pkg、preview.gif、project.json），安装包不再包含该项目。原始 Workshop 文件、用户自行导入的项目及 ZIP 导入能力不受影响。时间壁纸专项测试改为读取外部 elaina-original.zip 测试夹具，不再依赖安装包内置项目。

## 职责与性能

- HomeStageWindow：仅入口和预览文件预读。
- StageEntry：首页幕层展开/收回与生命周期。
- StageCurtain：复用 Paint、RectF 和渐变，不逐帧创建着色器或裁剪路径。
- PracticeActivity：首帧、方向稳定、开场、动态渲染的时序。
- PracticeBackdrop：预览与 startRendering 分离；启动幂等，关闭后不可重新启动。

遵循 KISS / YAGNI：复用原渲染器，不新增跨 Activity 的 WebView 缓存。幕层共享绘制（DRY），入口、时序和渲染各自负责一件事（SRP）。

## 验证边界

Instrumentation 检查真实首页点击、重复进入、逐帧禁止竖屏琴键、横屏可演奏和返回方向恢复，并继续原有六模式、即时修饰键、真实触摸、壁纸选择和中断测试。OEM 系统合成器的旋转动画仍需目标手机验证；模拟器的功能通过不能证明手机帧率。

本轮验证：Debug 构建成功；83 项单元测试通过、2 项可选测试跳过。PracticeInstrumentation 全部通过（含竖屏帧禁止琴键）；WallpaperImportInstrumentation 图片/视频/网页、开场期间无 WebView、系统 ZIP 入口、无效包回滚、原始 Workshop ZIP 导入通过。模拟器关闭 Vulkan 后完成补充测试。APK 35796278 字节，已检查压缩包中没有 default-wallpaper 条目。

录屏复核修正：首页方向固定为进入前的明确横/竖方向，不使用会重新锁定当前屏幕的 LOCKED；返回后焦点、形状与尺寸稳定 300ms 再收幕。默认背景完整进出使用 Android 原始 screenrecord 录制，不加速。大场景在模拟器录屏负载下出现过无响应，默认轻量背景录像与任意导入场景的性能不能等同。

最终录屏在 GPU host、720×1600 测试模拟器完成，完整检查首页→横屏→首页，无横排首页闪现；原速 MP4 位于 artifacts/luoxianlv-stage-entry-r2-20260928.mp4（根工作区）。固定竖屏录制画布导致横屏片段上下留黑。最终入口专项检查再次通过。


## Kotlin 光核实现（当前版本）

HTML 强化版已移植到原生 Canvas，不加入预渲染视频。首页展开 850ms，光核绘制由首页/演练场共用 StageCurtain + StageLightRenderer；光核坐标始终是窗口中心，大小按屏幕短边计算，横竖屏交换不改变尺寸。

横屏尺寸/焦点稳定后，统一的 1700ms 进度推进蓄光压缩、径向透明揭幕、双层光浪、飞散光线、壁纸景深和琴键出现。琴键开场压缩到 650ms 并嵌入揭幕后段；必须琴键就绪且幕层完全隐藏才允许演奏/启动动态壁纸渲染。退出先停止演奏，以反向光浪遮住背景，再按原有稳定方向检查收回首页。

渐变 Shader、Paint、Path、矩形、光线方向与随机种子预先创建复用。只在径向揭幕阶段使用一层 saveLayer + DST_OUT，不生成逐帧位图。隐藏、暂停和销毁时停止环境重绘/取消动画。关闭系统动画时直接完成相应阶段。

包内继续不包含伊蕾娜 scene.pkg，现有 ZIP 导入保持可用。不得将桌面 HTML 的流畅度作为 Android 帧率结论，需结合目标手机体验。


## 右侧签入口接入

HomeStageWindow 改为 112×60dp 的左圆右直磨砂侧签，移入 HomeOverview 标题下方、状态及启动行上方。侧签偏移到内容卡右边缘，开场坐标由实际窗口边界获取。去掉原插画下的 66dp 占位，再在标题下分配同等总高度；保持启动行原有尺寸、横向边距及逻辑。StageCurtain 的首页裁剪同步为左侧圆角，复用现有光核动画。

右侧签验证：Debug 构建与格式检查通过；720×1600 模拟器入口专项检查通过（点击、重复点击、横屏揭幕、竖屏返回）。核对实际首页截图，侧签齐右边缘且启动行保持原有布局。


## 完整壁纸预加载与后台保留（当前策略，取代此前延后加载）

首页恢复后 500ms 在内容后方挂载一份横屏尺寸的壁纸渲染器；使用 application context，完成首帧后暂停，避免首页持续解码。PreparedWallpaper 按选中项目和固定时间区分缓存，交给 PracticeActivity 时移交同一个 View/WebView，移除旧父节点和缓存引用。主页销毁/离开组合时仅释放尚未移交的缓存。

演练场在揭幕前等待真实壁纸 ready（静态背景等待解码）；首次启动很快点击、选择新壁纸等缓存未完成情况仍要等待，期间保持光核，而不是先展示 GIF 再替换。加载错误沿用既有预览兜底；后台暂停期间不计入 60 秒加载超时。

onPause 只清除自动播放就绪状态、暂停悬浮播放、释放当前音频输出、暂停背景和环境重绘，不 finish、不销毁键盘或壁纸。onResume 恢复原渲染器、重新建立音频输出，音区/半音保持；已按下的音符不自动续播。真正退出或 onDestroy 才销毁资源。系统杀死进程后的恢复属于重新加载，不能保证内存缓存仍存在。

验证新增：首页真实网页壁纸 ready 后进入、同一 renderer 引用被移交、按 Home 切后台后重新前置原 Activity、重新获得播放就绪，随后原有六模式/触摸/壁纸选择/中断回归通过。功能重用 existing renderer（DRY），缓存和 Activity 会话职责分开（SRP），只保留一个缓存实例（KISS / YAGNI）。

内置伊蕾娜 APK 的同一入口专项也已通过：完整 scene 首页预加载、引用复用、Home 后恢复原 Activity、退出方向恢复。两种 APK 均编译成功；Debug 单元测试 83 通过、2 可选跳过。


## 点击先转屏（当前时序）

取消首页 850ms 展开等待；StageEntry 在同一次点击事件中立即 launch。PracticeActivity 在 manifest 声明 sensorLandscape，由系统启动时请求方向，不再继承竖屏、等待首帧提交后才请求旋转。居中光核负责转屏遮罩，爆发揭幕仍等待横屏稳定及壁纸 ready。预加载与后台恢复保持不变。系统旋转动画的具体表现仍取决于机型。

此时序的内置伊蕾娜入口专项通过：首页预加载复用、重复点击、横屏揭幕、Home 后返回原演练场、最终退出恢复竖屏。Debug 两种包构建成功。


## 白色球体与碎片重组（当前版本）

按最新要求去掉所有核心描边、环、虹彩和玻璃材质。Android 13+ 用 RuntimeShader 解析球面法线，以中性白材质和柔和明暗表现体积；不是 Filament 网格球。旧系统使用同色径向渐变回退。112 块带薄厚度的随机几何碎片进行 XYZ 旋转、透视投影、面深度排序与三段光照，再归入实际琴键圆环坐标。固定随机种子保证重播可复现，分簇发射与随机延迟避免整齐放射。绘制资源预分配，动画结束完全停止。此版没有实现对壁纸的引力透镜折射，也未引入 Filament；先提供可直接在 APP 中体验的白球和碎片版本。

白球版验证：Debug/测试包编译通过，模拟器完整 PracticeInstrumentation 通过（预加载复用、Home 后回到原页面、六模式、真实触摸、壁纸选择、开场中断）。前台可见模拟器已安装内置伊蕾娜包并打开首页供用户体验。


## 液态反应堆核心表面

白球表面增加三个不同方向/速度的流场，解析计算法线扰动并投影到球面切平面；白色漫反射和窄高光表现流动褶皱，轮廓仅有约 4% 波动。保留无描边、无彩环、无玻璃透射的白色主体。每帧只更新时间 uniform，Shader 和 Paint 复用，作用范围限于球体包围矩形。参照用户描述的反应堆核心动感，并非对具体地图素材的精确复刻。

液态核心放大修订：基础半径从屏幕短边 12.5% 提至 19%（约放大 52%）；外轮廓使用三层非同步大尺度波形，叠加横纵呼吸与空间偏移。表面法线扰动增至 0.23，形成更宽的流动褶皱。GPU 绘制区域随形变扩展，避免波峰裁切；仍无边框或外环。


## 近圆液态核心＋背景透镜

轮廓波幅由 0.145/0.075/0.035 收回到 0.050/0.024/0.010，保留大核心尺寸与表面法线流动。Android 13+ 的 StageGravityLens 对 PracticeBackdrop 使用 RuntimeShader RenderEffect，单次背景采样在核心外缘作径向偏移，随爆发撤去；不截图读回、不添加描边或装饰环。额外离屏渲染只用于开场，结束及销毁时清除。幕层在背景准备完成前保持不透明，防止露出 GIF 占位；ready 后半透明幕允许看见背景弯曲。

背景显露时序修正：蓄能幕层始终不透明，不因 wallpaper ready 而变半透明。碎片开始释放后（进度 0.61）才开始揭幕，0.79 完成；预加载只决定资源是否可用，不决定提前露出背景。


## 独立退出：碎光归巢

exitStage 同步停止演奏并立即请求 portrait，再并行执行 620ms 琴键碎光回收。144 个预生成粒子按不同延迟、深度、弯曲量从八个琴键收向中心，幕层逐渐遮住舞台。等待竖屏尺寸稳定后结束 Activity，首页幕层以相同归一化进度 0.54 接续中心光群，720ms 贝塞尔弧线飞入侧签，最后一次轻亮并释放幕层。退出不复用白球/爆炸。粒子绘制和进度控制分离，复用画笔和路径；新增验证点击退出后立即请求竖屏且停止播放。

碎光退出增强：用短暂的深蓝灰底提高白色光群对比；粒子 144→192，尺寸约增至原来两倍，尾迹改为双层曲线（宽柔光＋窄亮芯），汇聚中心增加预缓存径向光晕，侧签接收亮度提升。不改变退出动画时长与立即转屏的顺序。


## 状态胶囊位入口（当前版本）

首页入口从右侧签改为状态胶囊同款的圆角按钮：删除 HomeStageWindow 侧签，「无障碍未开启 · 点击去开启」的状态胶囊换成「演练场」胶囊（音乐图标＋文案）。幕布仍从入口自身的窗口坐标展开，退出碎光飞回同一位置，转场与预热逻辑（StageEntry / StageCurtain / StagePrewarmEffect）不变；预热挂在 AppNavHost 根部，Tab 切换不再中断。无障碍引导改由「启动」按钮承担：无障碍未开启时点启动仍会弹出「启用无障碍」引导弹窗。
