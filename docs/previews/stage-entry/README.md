# 演练场入口 · 成品交互预览

启动：

```powershell
python docs/previews/stage-entry/serve.py --port 18459
```

浏览器打开 `http://127.0.0.1:18459/`。服务只绑定本机，并只提供明确列出的预览资源。

## 交互

- 首页舞台窗：进入横屏演练场；原有八个浅圆环连续展开为八个音符按键。
- 左上角返回：反向收回舞台窗；Esc 同样可返回。
- 半音、升调、自然音、降调在按下时切换；鼠标按住或数字键 1–8 演奏。
- 左上角壁纸：竖屏选择后回到演奏。
- 首页启动：显示预览用的悬浮播放器，可在演练场播放短练习曲。
- 浏览器左下角可重播开场、切换深浅色；首页设置可修改一言。

## 材质与过渡

首页保留 APP 的蓝灰渐变、插画、侧栏时钟、半透明操作控件。舞台窗不展示所选壁纸，使用浅凹面、细边缘反光和半隐藏的琴键圆环。进入约 1.18 秒、退出约 0.9 秒，使用同一 Canvas 中的同一组圆环进行位置、纵深和形状插值。壁纸在后半段才显露。系统减少动态效果时缩短过渡。

## 素材与边界

- 首页插画、静态回退背景、口琴 PCM 都读取当前 APP 已有资产。
- 伊蕾娜视频来自用户指定的 Workshop 3113554287 原项目 day 图层；本目录仅保留供 HTML 展示的 12 秒、1280 宽预览视频及首帧，不改写 Android 原项目。
- 开场音效仍留空，口琴音符使用实际采样。
- 本页用于展示拟落地的视觉与操作；浏览器模拟横竖屏尺寸变化，Android 原生转屏和完整 Wallpaper Engine 运行时尚未接入这套新动效。
- 本次仅新增 HTML 预览，未修改或发布 Android UI。


## 光缝开场修订（2026-09-28）

本轮只调整 HTML，未接入 Android。入口只显示演练场；点击后渐变玻璃展开，三层柔光以不同速度漂移，光缝延伸；外框在遮挡状态下横向展开，然后揭幕并显示琴键。默认使用轻量日落背景。

普通演示 3.6 秒，慢加载 6 秒；停留过渡可持续查看柔光，点击继续揭幕后接上动画。时间为视觉演示，不代表 APP 加载耗时。深浅色、退出、口琴音源交互保留。运行 `python serve.py --port 18460`，打开 http://127.0.0.1:18460/ 。


## 手持转屏修订

点击只推进到竖屏引导，不再自动变宽或按固定时间进入演奏。桌面采用固定 390×844 比例的手机模型，拖动模型、旋转条和模拟转横屏按钮控制同一角度状态。转到 88° 以上并稳定 300ms 才揭幕；中途转回会隐藏琴键并恢复引导。退出需转回竖屏才收回首页。手机浏览器使用实际 viewport / screen.orientation 变化，无陀螺仪权限请求；网页不会主动锁定方向。真实手机上的连续角度传感未实现，桌面连续转动为交互模拟。

验证：桌面 0° 等待、45° 保持引导、90° 揭幕与退出回到 0°；真实手机需另行体验。此修订仍只在 HTML 预览中，不修改 Android。


## 自动光核版本（当前）

入口点击后自动蓄光、旋转固定比例的手机模型，再从屏幕中心向外散开，揭出琴键。光核圆心始终位于设备中心，取消转手机提示、旋转条与拖动要求。此为 HTML 时序演示；不请求设备传感器权限，也不强制手机浏览器方向。


## 光核强化版

保留固定中心，增大珠光核心，加入向心细光、蓄光时环境压暗、核心压缩、双层径向光浪、有限数量的飞散光线及镜头横向反光。壁纸从中心开孔显露，带轻微景深推进。无额外音效、无反复闪屏。已在浏览器检查完整自动进出和采样帧，无控制台错误。


## 右侧磨砂入口

当前 HTML 入口为 112×60 的侧签，置于问候语后、启动区前，右侧与内容卡齐边、左侧 24px 圆角，仅显示演练场。光核开场从侧签实际边界展开。只调整 HTML，Android 尚未同步。
