# 下一版发布前检查

状态：用户已于 2026-09-28 重新明确授权发版，准备发布 v1.0.8（13）。此前因壁纸播放中断暂停的发布现已恢复；修复与回归见 `wallpaper-stream-fix-20260928.md`、`interaction-and-fixed-keys-20260928.md`。

当前验证：91 项单元测试中 89 通过、2 项可选测试跳过；小窗与悬浮球、独立音频焦点、三轮壁纸完整循环、禁止截图时固定琴键演奏与关闭开关后的识别恢复均通过；精简 Debug 构建和安装通过。手机公告采用 `.github/release-notes/1.0.8.json`。以下保留前期检查记录；最终签名、正式打包、OSS 上传及更新清单部署由 release 工作流执行。

## 相对 v1.0.7 的主要变化

- 新增演练场：游戏布局口琴、真实采样音色、长按延音、即时切换音区与半音，支持曲谱播放。
- 新增演练场进出场效果；点击入口先转横屏，后台返回保留演练场。
- 新增壁纸选择与预览，可导入打包 Wallpaper Engine 原始项目的 ZIP（文件夹选择入口已移除），也可从 QQ 等应用选择“导入落弦律壁纸”。支持的场景有兼容范围，不宣称能播放所有项目。
- 新增“世界很温柔 · 上杉绘梨衣”默认动态壁纸，以压缩 ZIP 随包安装到外部壁纸目录；加入默认关闭的声音开关和“演练场设置”，与口琴同播、后台停音。
- 壁纸提前准备，进入演练场复用渲染器；修复暂停与恢复时序、释放闲置预览和解码资源；开场及退场减少重复计算。
- 按键定位结合已识别按键和边框推算布局；点击与截图使用统一坐标，改善部分设备识别失败。
- 修复手势被打断后短时间内误触恢复播放，以及暂停后意外继续播放。
- 修复播放前台服务重复启动、快速启停引发的超时崩溃；针对已知系统小窗异常加入精确保护。
- 日志改为中文 UTF-8，补充本地崩溃堆栈与系统退出原因；壁纸、日志和诊断包放入应用专属外部目录，保留旧数据迁移。
- 页面切换减少重复布局、重组和壁纸缓存重建；模块按职责拆分，移除无用旧代码，中文注释保持必要约束。

## 检查结论与边界

已核查本地未提交改动、v1.0.7 后的功能范围、发布入口和手机端公告格式。沿用同一代码版本已经完成的验证：Debug / Release 单元测试各 86 项通过、2 项可选测试跳过；Release / 精简 Debug 构建通过；旧服务代码对照复现超时崩溃，修复版服务回归通过；诊断导出与外部存储测试通过。

本轮继续检查壁纸时间与生命周期脚本、Kotlin 格式、改动文件 UTF-8 无 BOM 和差异空白。没有为了检查而更改业务逻辑或重复构建相同 APK。

尚不能宣称“所有手机均无问题”：

- 导航测量确认部分绘制开销减少，但整体超时帧比例未改善，不能把公告写成“彻底解决卡顿”。
- 红魔系统小窗异常保护仍需对应真机验证。
- 全量 lint 有既有 API 标注、资源版本等问题，当前构建所需 lintVital 通过。

启停控制集中在服务内，复用现有通知和停止入口，不增加常驻线程；公告只保留用户能感知的变化。按单一职责和去重原则简化实现，不引入额外发布机制。
